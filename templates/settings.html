Cursor & OpenCode

Overrides persist in SQLite and replace env defaults at sync time. Leave a command blank to keep the env default ({{ env_cursor }} / {{ env_opencode }}).

To start agents: sync a project, open Terminal, then sign in inside each pane (Cursor OAuth / OpenCode provider). Rebuild the Docker image after Cursor CLI PATH changes; if a pane says command not found, set Cursor command to agent (alias cursor-agent also works).

Cursor (left pane)

Image installs Cursor CLI as agent (and cursor-agent) under /usr/local/bin. Authenticate inside the terminal pane — Anchor never passes GITHUB_TOKEN into agent env.

OpenCode (right pane)

OpenCode ships via npm in the Docker image (opencode-ai). Sign in from the pane on first use.
